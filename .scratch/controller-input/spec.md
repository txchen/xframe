# Offline controller input groundwork

Implement immutable sanitized gamepad snapshots and a pure little-endian single-controller packet encoder, based on the pinned reference documented in `reference.md`. Keep Y convention explicit (snapshot positive-down; wire negates Y), button and physicality masks separate, and timestamp/sequence injectable. Invalid analog values become neutral. Invalid timestamps fail without consuming a sequence. Sequence wraps UInt32 deliberately and resets on a new encoder session.

Tests compare neutral/A packets against bytes generated by running the pinned TypeScript implementation; cover all button masks, independent physicality, analog truncation, range clamping, Y direction, NaN/infinity, release-to-neutral, immutable prior state and sequence rollover/reset.

This module is intentionally not connected to WebRTC or macOS GameController. Do not advertise a gamepad, start input polling, send game commands or parse rumble yet. Tomorrow's integration must validate physical device discovery, one-time axis conversion, focus ownership, disconnect neutralization, input-channel handshake, failed sends/backpressure, host acceptance and teardown. No playable-controller claim is made from wire parity alone.

## Verification result

All four offline input tests passed, including byte-for-byte reference fixtures and sequence max-to-zero rollover, as part of the final 57-test suite repeated three times. No physical controller was present or required.
