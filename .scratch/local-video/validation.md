# Local Video Validation

Environment: Apple Silicon, macOS 27, Swift 6.4, macOS 27 SDK.

## Fixture

Generated by `scripts/make-test-video.sh`: 1920 × 1080, H.264, 60 fps, 12 seconds, 720 frames, BT.709, with B frames. FFprobe independently confirmed the dimensions, codec, frame count, frame rate, and B-frame presence. Generated media stays in the ignored `.build/fixtures/` directory.

## Automated Hardware Checks

`bash scripts/test.sh` passes all three tests, including both arguments of the playback test:

- Normal playback with alternating ±1 ms display callback jitter: all 720 frames decoded and selected in strictly increasing presentation order, with no skipped frames.
- A simulated one-second display stall: stale frames are skipped, output timestamps remain strictly increasing, and selected plus skipped frames account for all 720 decoded frames.
- Decoder output is verified as 1920 × 1080 NV12 backed by IOSurface. The active VideoToolbox session confirms hardware acceleration.
- The decoded queue never exceeds 16 frames and drains at EOF.
- Stopping while the queue is full wakes the producer and clears the queue.
- A missing input file produces a visible failure state.
- Decoding alone leaves the presented-frame counter at zero.

The standalone Command Line Tools installation requires an explicit framework search path and runtime path for its bundled Testing.framework. `scripts/test.sh` supplies those paths; no third-party testing dependency is downloaded.

## Native Window Checks

- Opened the fixture through the native file picker and visually confirmed moving video and the hardware status overlay.
- Verified native full-screen entry/exit with output changing between 1920 × 1080 and 3840 × 2160 backing pixels.
- Verified replay and stop back to the static test pattern.
- After correcting timestamp boundary sensitivity, an uninterrupted 12-second windowed pass reported decoded 60.0 fps, presented 60.0 fps, zero skipped frames, and an empty queue at EOF.

## Limits

- This is a short synthetic playback validation, not a long-duration stability benchmark or a streaming latency measurement.
- Physical cross-display moves remain unverified.
- Audio, pause, seek, HDR, rotation, cropped/non-square-pixel video, adaptive streaming pacing, and MetalFX remain outside this increment.
- SDR color conversion is implemented in the shader and visually inspected; it has not undergone a calibrated color accuracy test.
- Window transitions may skip frames while the UI is busy. Counters report these skips rather than hiding them.
